VIRUSTOTAL & MALWARE ANALYZERS DETECTIONS EXPLAINED

Understanding false positives and how security tools flag our files.

Why files are flagged

  • Our installer and products are obfuscated with VMProtect/ConfuserEx to prevent leaks or dumping.
  • The installer downloads additional files from our official GitHub repos.
  • VMProtect/ConfuserEx + downloader is heavily used by malware, so AVs flag it.
  • In bin folder we contain Velocity files and files that are can be flagged as trojan since they are used to read and write memory.
These are false positives. Files are completely clean.

Complaining about VirusTotal without an actual issue will get ignored by our team.
